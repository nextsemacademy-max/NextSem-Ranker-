## 🚀 GitHub Pages Deployment
To deploy this repository to GitHub Pages:
1. Go to **Repository Settings** ➔ **Pages** (`https://github.com/nextsemacademy-max/NextSem-Ranker-/settings/pages`).
2. Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your web application will be live at `https://nextsemacademy-max.github.io/NextSem-Ranker-/`.
